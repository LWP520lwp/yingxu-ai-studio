# Studio 画布

画布与科普视频分别保存。首页的画布草稿打开 Studio；科普草稿继续进入科普制作模块。

## 操作

- 项目名称可以在顶部修改；修改后会同步到平台草稿列表。
- 左侧工具轨创建文字、图像、视频、声音、生成器与分组。双击文字节点可直接输入，右侧面板也可编辑。
- 拖动右端口到另一个节点左端口，建立输入参考。反向拖线也可以；重复连接和循环引用会被拒绝。键盘聚焦端口后按回车，再到另一个节点相对端口按回车，也可连接。
- 拖线到空白处可以创建相连的生成器。图像参考会默认准备视频，文字参考会默认准备图像。创建节点不会调用生成接口。
- 选择工具支持框选和 Shift 多选。抓手、空格拖动与中键拖动可平移；滚轮缩放。`V` 选择、`H` 抓手、`T` 文字、`F` 定位所选内容。
- 更多画布操作内可选择线条网格、点阵或纯色底纹，选择会随草稿保存，也可撤销。
- `Ctrl/Cmd+Z` 撤销、`Ctrl/Cmd+Shift+Z` 重做、`Ctrl/Cmd+D` 创建副本。一次拖动只产生一次撤销记录，拖动期间完成的生成结果会保留。
- 图片支持裁切、分图、放大、蒙版编辑与 AI 新视角。新视角面板的机位图是要求示意，结果需要真实模型生成。视频可提取首帧和尾帧。
- 视频模式可以选择导演 Skill、模型、画面比例、时长和首尾帧。先准备 Skill，再检查生成要求；准备动作不会提交生成。
- 多选至少两个已有视频后，使用多选工具条的视频编排按钮。可编辑片段顺序、入出点、音量、串播预览并导出含真实素材的编排 ZIP。ZIP 不等于服务端渲染后的 MP4；科普成片由科普模块合成。

## Codex

使用者需要先在自己的计算机安装并登录 Codex CLI。终端运行：

```powershell
npm run codex:bridge
```

桥接只监听 `127.0.0.1:4599`。将终端显示的临时令牌填入画布 Codex 面板，点击“连接并读取模型”。令牌在桥接进程退出后失效，不包含在仓库中。也可运行 `scripts/start-dev.ps1 -WithCodexBridge` 一起启动；默认启动不启用桥接。

Codex 仅获取当前草稿的文字概要与连接，不读取媒体二进制或平台密钥。方案最多新增40个节点，先预览再确认；不能通过方案执行任意命令、删除已有节点或自动提交图像／视频生成。模型请求使用当前 Codex 账号的额度。

部署在远程服务器时，每位使用者仍需在自己电脑启动桥接；部署者不能借此共享本机 Codex 登录。默认只允许本机开发页面来源；更改页面域名需显式配置 `CODEX_BRIDGE_ORIGINS`。

## 模块与验证

`src/atlas-engine/studio` 内，`studio-document` 管理文档与历史；`useStudioGestures` 管理输入；`studio-tasks` 管理有界生成、取消与任务恢复；`studio-media` 管理素材事务；`studio-host` 处理带项目范围的主站命令。扩展节点沿用稳定的数据协议，以兼容已存草稿。

画布的图片／视频生成经平台受认证接口进入账号池。文本创作入口使用 Codex；声音可以导入播放，画布尚无独立音频生成接口。图像反推说明仍需图像理解接口接入。模型目录可用和连接测试通过，并不能替代真实供应商生成验收。

运行 `npm test` 检查网页、画布与桥接；`npm run typecheck --workspace apps/canvas-engine` 检查画布类型，`npm run build` 重建完整网页。画布静态产物由构建生成，不提交到仓库。
